# Gym Membership Management System

## Project Overview
This is a menu-driven application developed using C programming. It helps manage gym members, membership plans, payments and membership renewals.

## Features
- Register new gym members
- View all members
- Search members by ID
- Display membership plans
- Assign membership plans
- Record payment details
- Renew memberships
- Generate reports
- Save and load records using file handling

## Membership Plans
| Plan | Duration | Fee |
|---|---:|---:|
| Monthly | 30 Days | ₹1,500 |
| Quarterly | 90 Days | ₹4,000 |
| Half-Yearly | 180 Days | ₹7,000 |
| Yearly | 365 Days | ₹12,000 |

## Technologies Used
- C Programming
- Structures
- Functions
- Arrays
- File Handling

## Project Files
- `Main.c` – Main function and menu
- `Gym_functions.c` – Function definitions
- `Gym_management.h` – Structures and function declarations

## How to Compile and Run

Compile:
```bash
gcc Main.c Gym_functions.c -o gym
```

Run on Windows:
```bash
.\gym.exe
```
